# Security policy

NetworkSense is pre-alpha and maintained by one human with agent assistance.
Only the latest `main` is supported; there are no maintained release branches.

Please do not open a public issue for a suspected vulnerability. Use GitHub's
Security tab and private vulnerability reporting, or email
`licensing@djcdevelopment.com` with a subject beginning `[SECURITY]`.

Expect acknowledgement within seven days and, within 90 days, a fix,
mitigation, or published accepted-risk disposition. Please hold public
disclosure for 90 days or until a fix ships, whichever comes first. There is
no bounty program.

This repository's source, build/release tooling, package boundary, and mod
deployment helpers are in scope. Services owned by another repository and
retired pre-split checkouts are out of scope.
